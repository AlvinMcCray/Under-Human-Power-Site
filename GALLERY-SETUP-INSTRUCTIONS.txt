## How to Add New Photos:

**IMPORTANT:** To add images, edit the JavaScript in gallery.html around line 334:

```javascript
const galleryImages = {
    stage1: [
        'DarrellStandingOnPeak.jpg',
        'DarrellAndPeak.jpg',
        'MtnTopLake.jpg',
        // ADD MORE STAGE 1 IMAGES HERE
    ],
    stage2: [
        'MtnTreeClouds.jpg',
        // ADD MORE STAGE 2 IMAGES HERE
    ],
    // etc...
};
```

**Steps to add new photos:**

1. Upload your image file to the project root folder
2. Open gallery.html in a text editor
3. Find the `const galleryImages = {` section (around line 334)
4. Add your new filename to the appropriate stage array
5. Save and push to GitHub

**Example - Adding 3 new Stage I photos:**

```javascript
stage1: [
    'DarrellStandingOnPeak.jpg',
```
